## 재현 방법

프로젝트 루트에서 다음을 실행합니다. Python 3.9 이상이 필요하고, 두 번째 도구에는 sqlite3 CLI가 필요합니다.

```bash
python3 tools/verify.py
python3 tools/verify_cli.py
```

Python 도구의 출력과 `results/verification.txt`, CLI 도구의 출력과 `results/cli-verification.txt`에서 각각 42개·12개 PASS를 확인할 수 있습니다. 실제 CLI 입력·출력은 `results/cli-session.txt`에 생성됩니다. 이 원시 로그들은 실행 환경별 파일로 Git 추적에서 제외합니다.

기존 사용자 DB는 사용하지 않으며 메모리 DB와 새 임시 파일 DB에서 실행합니다. 쿼리별 결과 파일은 실행 결과로 갱신됩니다.

## 검증하지 않은 범위

GUI 도구, 실제 대규모 성능과 처리 시간, 여러 사용자 동시 실행, 동시 대여 방지입니다. 인덱스 사용 확인을 속도 향상 측정으로 해석하지 않습니다.
